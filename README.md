# The Last Light: Android download

A puzzle-adventure game by **Third Heaven Studios**.

## ⬇️ [Download the game (Android)](https://github.com/hbuhrmanlll/the-last-light-updates/releases/latest/download/the-last-light.apk)

### How to install
1. Tap the download link above on your Android phone.
2. Open the downloaded file **the-last-light.apk**.
3. If Android asks, allow your browser to install apps, then tap **Install**.
4. If Google Play Protect warns about an unknown app, tap **More details → Install anyway**.

### Updates
You only need to do this once. After that, the game tells you when a new version is ready:
open the game, tap **Update**, then tap **Install**. Your progress is kept.
